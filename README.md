# CalculatriceWS : TP2 SOA (Jakarta XML Web Services)

1. Ouvrir le dossier dans IntelliJ (pom.xml > Open as Project), JDK 17+, Maven > Reload project.
2. Lancer serveur.ServeurJWS
3. WSDL : http://localhost:8686/calculatrice?wsdl
4. SoapUI : New SOAP Project avec ce WSDL, puis tester somme, multiplication, soustraction, division.
